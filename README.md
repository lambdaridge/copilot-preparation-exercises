# Copilot Exercises - C# Console Application

This is a simple C# console application for practicing GitHub Copilot features.

## Quick Start

### Visual Studio 2022
1. Open `CopilotExercises.csproj`
2. Press F5 to build and run

### Visual Studio Code
1. Open this folder in VS Code
2. Run in terminal: `dotnet build`
3. Run in terminal: `dotnet run`

## What's Included

### Exercise Files by Topic:

**Exercise 1: Inline Suggestions**
- `Exercise1-InlineSuggestions/Calculator.cs` - Practice inline code completions
- `Exercise1-InlineSuggestions/CalculatorTests.cs` - Automated test suite

**Exercise 2: Chat Ask Mode**
- `Exercise2-ChatAskMode/TaskManager.cs` - Practice asking Copilot questions

**Exercise 3: Chat Agent Mode**
- `Exercise3-ChatAgentMode/DataProcessor.cs` - Practice letting Copilot make changes

**Project Files:**
- `Program.cs` - Main entry point that uses all classes
- `CopilotExercises.csproj` - Project configuration
